# 使用与开发

## 使用

应用安装在 `/Applications/菜单栏面板.app`。点击菜单栏九宫格按钮展开，再点一次或按 Esc 收起。若按钮被系统收起，先用系统双箭头展开，再按住 Command 把九宫格按钮移到靠右位置；也可以从「应用程序」重新打开 App 来显示面板。

每行十项，自动换行；项目过多时可纵向滚动，不限制项目总数。支持按名称搜索，名称自动换行完整显示，鼠标悬停也可查看名称。每次打开面板自动重新扫描。右上角文字「设置」可退出或打开辅助功能设置。

首次独立启动若提示未授权，在「系统设置 → 隐私与安全性 → 辅助功能」允许「菜单栏面板」。列表里没有时，点加号选择 `/Applications/菜单栏面板.app`，然后回到面板点「已允许，重新读取」。授权由用户操作，不修改系统隐私数据库。

## 界面与系统限制

这是一个独立的九宫格按钮，不替换系统双箭头。面板显示应用图标和名称；系统项目使用对应符号。同一应用的多个菜单栏项目分别列出并编号，目前不复制每个状态图标的动态数值。

枚举运行中应用通过辅助功能公开的菜单栏项目；没有辅助功能入口、没有运行或被应用自行关闭的图标无法保证获取。操作原菜单，不把应用主窗口当作菜单的替代品。原菜单的位置仍由目标应用与 macOS 决定。原生菜单无法打开时明确显示错误。

macOS 27 的收起项目可能有重叠坐标，因此不使用坐标点击。优先通过可唯一识别的 MenuBarAgent 活动代理操作，无法匹配时使用原应用的 AXExtrasMenuBar 项目。不会更改其他应用的隐藏策略、退出其他菜单栏工具或设置网络、显示等系统选项。

## 构建

需要 Xcode 命令行工具。无第三方依赖。在项目目录执行 `./build.sh`，产物为 `build/菜单栏面板.app`，使用本机临时签名。编译使用本机架构，当前为 Apple Silicon。重新签名后 macOS 可能要求重新授权辅助功能。

## 0.1.1：菜单打开后的超时误报修复

AXPress 可能进入目标应用的菜单跟踪循环，菜单已出现但调用尚未返回，最终产生 -25204（cannotComplete）。旧版把它当作失败，再执行 AXShowMenu 并重新激活面板，可能打断已经打开的菜单。苹果文档明确提示：这种超时不等于动作失败。

修复：发起一次点击后检查原菜单的可见尺寸以及目标进程新增的屏幕窗口；只有明确返回 actionUnsupported 才尝试 AXShowMenu。遇到 cannotComplete 不再重复触发，也不主动拉回面板；无法确认时仅在下次用户打开面板时显示提示，避免抢走原菜单焦点。

本机针对 WorkBuddy 验证：记录到 result=-25204、observed=true（检测到已展开菜单或目标应用新出现的屏幕窗口），也记录到 result=0、observed=true。验证未覆盖所有第三方 App。普通启动不记录诊断日志；开发时可设置 MENU_GRID_DIAGNOSTICS=1，只输出动作错误码和是否检测到可见结果，不输出菜单内容。

依据：[Apple AXUIElementPerformAction 文档](https://developer.apple.com/documentation/applicationservices/1462091-axuielementperformaction)。

## 0.1.2：紧凑布局与完整名称

移除空标题栏与重复的“菜单栏 / 数量”标题，面板顶部改为一行搜索框和文字“设置”。取消手动刷新按钮，打开时自动扫描。面板高度按当前内容计算，搜索结果变少时随之收缩。

图标名称不再省略，允许自动换行；各行按最长名称计算高度，仍保持每行十个，超过可用高度纵向滚动。保留鼠标悬停名称提示。

本机已编译并检查实际截图：顶部紧凑；MiniMax Code、WorkBuddy AI、TextInputMenuAgent 等名称完整显示；系统菜单与第三方应用的打开逻辑保持 0.1.1 修复。未新增常用置顶或拖拽排序功能。

## 0.1.3：常用图标置顶

右键图标选择“置顶”，会移到列表前面并显示小图钉；右键“取消置顶”恢复普通排序。多个置顶项按置顶先后排序，不会因扫描或名称变化重新按字母排序。搜索也保留置顶优先。

置顶顺序保存在本机 UserDefaults 的 pinnedMenuItems.v1，不同步到仓库。标识使用应用 bundle identifier 与菜单项 AXIdentifier；缺少 AXIdentifier 的项目用应用内部序号区分，不使用进程 PID 或可变化的状态文案。因此重启面板和大部分应用后可保留，个别应用若改变无标识菜单项的内部顺序，可能需要重新置顶。应用未运行时不显示其图标，但仍保留置顶记录，之后运行会回到原置顶顺序。

本机验证：将 Xnip、WorkBuddy 依次置顶，确认排在前两位；退出并重新运行面板后，两者及顺序保留。实测右键“取消置顶”恢复普通排序。测试所用置顶已清除，默认不替用户选择常用项目。
